---

**Bu belge,**
bireysel ve kurumsal finansal disiplinin sağlanabilmesi için
**gider kalemlerinin sistematik bir şekilde tanımlanmasını** amaçlamaktadır.

- **Zorunlu giderler:**
Yaşamın devamı için gerekli olan barınma, gıda, sağlık, ulaşım, eğitim ve
finansal yükümlülükler gibi kalemleri kapsar.

- **Tercihe bağlı giderler:**
Kişisel tercihler, yaşam tarzı ve yatırım kararları doğrultusunda ortaya
çıkan abonelikler, eğlence, lüks harcamalar ve varlık alımları gibi kalemleri
içerir.

**Belge, bu ayrımı yaparak:**
- **Finansal değer takibi** için standart bir çerçeve sunar.
- **Gelir-gider yönetimini** kolaylaştırır ve net değerin ölçülmesine
  yardımcı olur.
- **Kısa ve uzun vadeli finansal planlama** için pratik bir referans sağlar.
- Muhasebe, kişisel finans yönetimi ve yazılım geliştirme projelerinde
  kullanılabilecek **modüler bir veri modeli**  oluşturur.

## Gider Kalemleri
| Zorunlu Gider Kalemleri   | Açıklama |
|---------------------------|----------|
| Barınma                   | Kira, aidat vb. |
| Faturalar                 | Elektrik, su, internet, telefon vb. |
| Gıda                      | Temel gıda ürünleri, işlenmiş gıdalar. |
| Giyim                     | Zorunlu kıyafet ihtiyaçları. |
| Sağlık                    | İlaç, muayene, tedavi giderleri. |
| Ulaşım                    | Toplu taşıma, bilet, abonman. |
| Ulaşım-Akaryakıt          | Araç yakıt giderleri. |
| Ulaşım-Ek Maliyetler      | Araç bakım, otopark, sigorta dışı masraflar. |
| Eğitim                    | Okul, kurs, kitap, materyaller. |
| Kredi Borcu               | Banka kredileri (ev, araba, ihtiyaç vb.), kredi kartı borçları. |
| Sigorta/Sosyal Güvenlik   | Zorunlu sigorta primleri, SGK kesintileri. |
| Beklenmedik Harcamalar    | Acil durumlar, tamir, ani sağlık veya aile giderleri. |

| Tercihe Bağlı Gider Kalemleri | Açıklama |
|-------------------------------|----------|
| Varlık Alımları               | Yatırım amaçlı veya büyük ölçekli alımlar (ev, araba, altın vb.). |
| Abonelikler                   | Dijital hizmetler (Netflix, Spotify, oyun abonelikleri vb.). |
| Eğlence/Hobi                  | Kişisel aktiviteler, hobiler, spor, seyehat vb.|
| Lüks Harcamalar               | Zorunlu olmayan tüketim (markalı ürünler, özel etkinlikler, oyunlar, dijital içerikler vb.). |
| Borç Verme                    | Kişisel finans hareketleri, başkalarına verilen borçlar. |
